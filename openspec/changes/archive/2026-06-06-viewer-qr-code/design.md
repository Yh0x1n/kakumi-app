## 1. Architecture Decisions

### 1.1 QR State Lives in TournamentState

**Decision:** Add QR vars + handlers to `TournamentState`, not a new state class.

**Why:**
- QR lifecycle tied 1:1 to current tournament selection. No need for separate state.
- Existing pattern: `TournamentState` owns workspace-scoped state (lifecycle, selection). QR is same scope.
- No cross-tab or shared-state needed — QR generated by operator in workspace only.
- Simpler than creating `TournamentQRState` with substate plumbing.

**Alternatives considered:**
- New `TournamentQRState(Substate)`: too heavy for 4 vars + 2 handlers. Adds substate sync complexity.
- `SharedState`: overkill. QR not collaborative across users.

### 1.2 QR Generation as Standalone Helper Function

**Decision:** `_make_qr_data_url(url: str) -> str` lives as a module-level function in `kakumi_app/services/viewer_service.py` (or a dedicated `kakumi_app/services/qr_helper.py`).

**Why:**
- Pure function: input URL, output data URI. No DB, no state, no side effects.
- Service class is for DB-bound operations (code generation, validation). QR encoding is stateless.
- But placing in `viewer_service.py` alongside `generate_viewer_code()` keeps viewer-related code together. No need for separate module for 15 lines.

**Final placement:** New file `kakumi_app/services/qr_helper.py`. Rationale:
- `viewer_service.py` already 112 lines. Adding QR encoding mixes concerns.
- `qr_helper.py` is importable without pulling in `rx.session()` overhead.
- Easier to unit test in isolation.
- Can be reused later if QR needed elsewhere (e.g., public display).

### 1.3 Data URI over File Storage

**Decision:** QR image served as `data:image/png;base64,...` data URI.

**Why:**
- **SSR-safe:** No file I/O. Works in Reflex SSR where filesystem writes may be restricted.
- **No cleanup:** No temp files to delete. No stale QR images accumulating on disk.
- **No URL routing:** No static file serving needed.
- **Small payload:** QR code at smallest size (~290x290px) is ~1-2KB base64. Trivial for Reflex state sync.
- **Same origin:** No CORS. Data URI rendered directly in `<img src=...>`.

**Tradeoff:** Slightly larger state payload (~2KB). Negligible for occasional generation.

### 1.4 No Real-Time Countdown Timer

**Decision:** Static "expires at" timestamp, not live countdown.

**Why:**
- QR card visible only in operator workspace (not a dashboard).
- Real-time timer requires polling or websocket ticks. Overengineered for 5h expiry.
- User refreshes page to see updated time. Acceptable UX.
- Spec explicitly marks countdown out of scope.

## 2. Data Flow Diagrams

### 2.1 QR Generation Flow

```
Admin clicks "Generar QR" button
       │
       ▼
TournamentState.generate_qr()              [event handler]
       │
       ├─ 1. Check tournament selected. If none → toast error, return.
       │
       ├─ 2. Call ViewerService.generate_viewer_code(tournament_id)
       │         │
       │         ├─ rx.session() as session
       │         ├─ session.get(Tournament, tournament_id)
       │         ├─ new_code = secrets.token_hex(4)       ← 8-char hex
       │         ├─ tournament.viewer_code = new_code
       │         ├─ tournament.viewer_code_generated_at = utcnow()
       │         ├─ session.commit()
       │         └─ return new_code
       │
       ├─ 3. If code is None → toast "Tournament not found", return.
       │
       ├─ 4. Build url = f"/viewer/dashboard/{tournament_id}?code={code}"
       │
       ├─ 5. Call _make_qr_data_url(url)
       │         │
       │         ├─ qrcode.make(url) → PIL Image
       │         ├─ BytesIO → PNG → base64 → "data:image/png;base64,..."
       │         └─ return str
       │
       ├─ 6. Update state:
       │     self.qr_data_url = data_uri
       │     self.qr_code_text = code
       │     self.qr_generated_at = utcnow().isoformat()
       │     self.qr_expires_at = (utcnow() + 5h).isoformat()
       │
       └─ 7. Toast.success("QR generado")
                │
                ▼
         UI re-renders:
         rx.cond(qr_data_url != "", _qr_card_generated, _qr_card_empty)
```

### 2.2 QR Scan Flow

```
Spectator scans QR code
       │
       ▼
URL: /viewer/dashboard/42?code=a1b2c3d4
       │
       ▼
ViewerState.load_viewer_dashboard()     [on_load handler]
       │
       ├─ 1. Extract ?code= param:
       │     self.viewer_code = self.router.page.params.get("code", "")
       │
       ├─ 2. Extract route param:
       │     tournament_id = self.router.page.params.get("tournament_id")
       │
       ├─ 3. If no tournament_id → redirect /viewer
       │
       ├─ 4. Call check_viewer_access(code, tournament_id)
       │         │
       │         ├─ ViewerService.validate_viewer_code(code)
       │         │     ├─ _is_code_locked(code)? → None
       │         │     ├─ DB: SELECT * FROM tournaments WHERE viewer_code=?
       │         │     ├─ _is_code_expired(tournament)? → None
       │         │     ├─ _reset_attempts(code) → return tournament
       │         │     └─ None → redirect /viewer
       │         │
       │         └─ tournament.id == tournament_id? → True/False
       │
       ├─ 5. If access granted:
       │     ├─ self.current_tournament = dump
       │     ├─ self.load_categories()
       │     └─ toast.success()
       │
       └─ 6. If denied:
             ├─ self.access_denied = True
             └─ redirect /viewer
```

### 2.3 Regeneration Flow

```
Admin clicks "Regenerar QR"
       │
       ▼
TournamentState.regenerate_qr()         [event handler]
       │
       └─ Same as generate_qr() flow:
          ├─ ViewerService.generate_viewer_code(tournament_id)
          │     └─ Overwrites viewer_code + viewer_code_generated_at in DB
          │        Old code no longer exists → invalidated
          ├─ _make_qr_data_url(new_url)
          ├─ Update all state vars
          └─ Toast.success("QR regenerado")
```

```python
    @rx.event
    async def generate_qr(self) -> None:
        """Generate viewer code + QR for current tournament."""
        tournament_id = self._get_tournament_id()
        if tournament_id is None:
            yield rx.toast.error("No tournament selected")
            return

        code = ViewerService.generate_viewer_code(tournament_id)
        if code is None:
            yield rx.toast.error("Could not generate viewer code")
            return

        url = f"/viewer/dashboard/{tournament_id}?code={code}"
        data_uri = _make_qr_data_url(url)

        now = datetime.datetime.utcnow()
        expires = now + datetime.timedelta(hours=5)

        self.qr_data_url = data_uri
        self.qr_code_text = code
        self.qr_generated_at = now.strftime("%Y-%m-%d %H:%M UTC")
        self.qr_expires_at = expires.strftime("%Y-%m-%d %H:%M UTC")

        yield rx.toast.success("QR generado")

    @rx.event
    async def regenerate_qr(self) -> None:
        """Regenerate viewer code + QR (invalidates previous code)."""
        # Same logic as generate_qr — ViewerService.generate_viewer_code()
        # overwrites both viewer_code and viewer_code_generated_at in DB.
        async for event in self.generate_qr():
            yield event
```

### 3.5 `kakumi_app/services/qr_helper.py` — new file

```python
"""
QR Code generation helper.
Produces SSR-safe data URIs with no file I/O.
"""

from io import BytesIO
import base64

import qrcode


def _make_qr_data_url(url: str) -> str:
    """Generate a QR code image and return as base64 data URI.

    Args:
        url: URL string to encode in QR.

    Returns:
        Data URI string: data:image/png;base64,<encoded>
    """
    qr = qrcode.make(url)
    buf = BytesIO()
    qr.save(buf, format="PNG")
    b64 = base64.b64encode(buf.getvalue()).decode()
    return f"data:image/png;base64,{b64}"
```

### 4.1 Structure

```
┌─────────────────────────────────────────────┐
│  QR de Espectadores                          │

│  │  ├─ "Expira: 2026-06-06 15:30 UTC"  │   │

│  │                                       │   │

│  │     disabled when no tournament       │   │
│  └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 4.2 States

| State | Condition | Shows |
|-------|-----------|-------|
| Empty (no QR) | `qr_data_url == ""` | "Generar QR" button |
| Generated | `qr_data_url != ""` | QR image + code text + expiry + "Regenerar QR" |
| Disabled | `has_selected_tournament == False` | "Generar QR" disabled |
| Loading | n/a (not needed — sync handler) | — |

### 4.3 QR Image Sizing

- `width="200px", height="200px"` — readable on desktop. QR module size ~5px at 200x200.
- No max_width constraint (card width ~100% of grid cell).
- Maintains aspect ratio via `rx.image` default behavior.

### 4.4 Expiry Display Format

`"Expira: {YYYY-MM-DD HH:MM} UTC"` e.g. `"Expira: 2026-06-06 15:30 UTC"`:

- Generated via `datetime.datetime.utcnow().strftime("%Y-%m-%d %H:%M UTC")`.
- Static text. No live countdown.
- When code expires, QR becomes invalid at DB level. QR card state only updates on page reload or regeneration.

### 4.5 Button Layout

- **Empty state:** Single centered "Generar QR" button (default `variant="solid"`).
- **Generated state:** "Regenerar QR" button (outline variant), centered below expiry text.
- Both buttons disabled when `has_selected_tournament == False`.

## 5. Contracts

### 5.1 `ViewerService.generate_viewer_code(tournament_id: int) -> Optional[str]`

```
Input:  tournament_id — int, PK of Tournament
Logic:  rx.session → get Tournament → secrets.token_hex(4) → save → commit
Output: 8-char hex string on success, None if tournament not found
Side:   Commits viewer_code + viewer_code_generated_at to DB
```

### 5.2 `_make_qr_data_url(url: str) -> str`

```
Input:  url — string to encode (e.g. "/viewer/dashboard/42?code=a1b2c3d4")
Logic:  qrcode.make → BytesIO → base64
Output: "data:image/png;base64,<encoded>" string
Side:   None. Pure function.
```

### 5.3 `TournamentState.generate_qr() -> None`

```
Signature: async def generate_qr(self) -> None
Pre:       self.current_tournament is not None
Flow:      get_id → ViewerService.generate_viewer_code → _make_qr_data_url → set state
Post:      qr_data_url, qr_code_text, qr_generated_at, qr_expires_at populated
Error:     toast if no tournament or generation fails
```

### 5.4 `TournamentState.regenerate_qr() -> None`

```
Signature: async def regenerate_qr(self) -> None
Pre:       self.current_tournament is not None
Flow:      Delegates to generate_qr() (identical logic — ViewerService overwrites code)
Post:      Old viewer_code invalidated. New code + timestamp in DB. State vars refreshed.
```
